## Read this first

- **Small N.** Each case ran twice in total: once in v1 and once in v2, with different seeds. A difference of one or two cases is noise, not a measured effect.
- **C1 is "seen".** The prompt was changed after the agent failed the same fault type during development, so C1 is never counted as held out. C2-C5 were held out in v1 and seen in v2.
- **The scripted baseline cannot read operator notes, by design.** In group B it runs without the note; its violations are counted below. Group B is therefore not a fair contest.
- **The naive scan is a reference only** (10 fixed positions, 1 ms).
